# PvG3 — Портал

Настоящий **3D-shooter-головоломка в духе Portal**, написанная на **чистом C** —
без движка, без внешних ассетов, без библиотеки для 3D. Весь рендер:
перспективная проекция, z-buffer, освещение по нормалям граней, растризация
треугольников — написан вручную в `src/game.c`. Платформенный слой просто
блотит программный кадр на экран.

## Сюжет

Мы с другом **Кириллом** попали в секретную лабораторию GLaDOS-подобной
машины. Нас, как тестируемых, гоняют через **тест-камеры**: нужно стрелять
**порталами**, переносить **кубы** на **кнопки**, открывать **двери** и
добираться до светящегося выхода.

## Как играть

- **Слева — джойстик движения** (потяни пальцем), **справа — свайп камерой**.
- Справа внизу три кнопки: **СИНИЙ портал**, **ОРАНЖЕВЫЙ портал**, **ВЗЯТЬ/БРОСИТЬ куб**.
- Тапни портал-кнопку (наводишься камерой на стену/пол) — на этой поверхности
  появится портал. Войди в один портал — выйдешь из другого, сохранив импульс.
- Подойди вплотную к кубу и нажми **ВЗЯТЬ** — куб повиснет перед камерой;
  стань на кнопку и нажми **БРОСИТЬ** — дверь откроется.
- Дойди до **светящегося выхода** — следующий уровень.

| Уровень | Название        | Что изучить                          |
|---------|-----------------|--------------------------------------|
| 1       | ТЕСТ-КАМЕРА 01  | Основы: найди выход                  |
| 2-3     | ТЕСТ-КАМЕРА 02-03 | Куб на кнопку → дверь               |
| 4       | ТЕСТ-КАМЕРА 04  | Лабиринт, порталы между стенами      |
| 5       | ТЕСТ-КАМЕРА 05  | Высота: портал на башню              |
| 6       | ТЕСТ-КАМЕРА 06  | ФИНАЛ: огромный зал с колонной       |

## Структура

```
src/game.h, src/game.c          — вся игра (3D-математика + растеризатор, кириллица)
src/android_main.c              — Android-слой: native_app_glue + EGL/GLES2
tools/host_test.c               — десктоп-проверка (рендерит BMP-скриншоты)
tools/sim_test.c                — автосимуляция (стабильность)
AndroidManifest.xml             — app.pvg3, NativeActivity, Android 10+
LICENSE                         — MIT
.github/workflows/Build.yml     — сборка arm64+arm32 в один APK
```

## Сборка (Android APK)

Воркфлоу собирает **обе** ARM-архитектуры из одних исходников и пакует их в
**один** APK: `arm64-v8a` (64-бит) и `armeabi-v7a` (32-бит), min API 29
(Android 10+), target API 34. На выходе — артефакт `PvG3-Android-arm64-arm32`.

## Проверка локально (без устройства)

```sh
gcc -O2 -Wall -Isrc src/game.c tools/host_test.c -o host_test -lm
./host_test   # пишет shots/menu.bmp и shots/play.bmp
```
