# PvG3 — Растения против гусей

Лейн-защита в духе **Plants vs. Zombies**, написанная на **чистом C** — без
движка и внешних ассетов. Вся графика рисуется процедурно, текст — встроенным
шрифтом с кириллицей.

## Сюжет

Мы с другом **Кириллом** прошли через портал в этот мир. Все гусей украли
**утки**: их **королева** забирала гусей и переделывала их в уток — и вот
переделанные гуси идут на наш дом! С нами подружился **Хлебушек** — гусь
(он называет себя гусем), который, правда, влюблён в королеву уток...

Защищай газон растениями, отбивай волны гусей, а на последней волне —
**босс-бой с Королевой Уток**. Сюжет подаётся репликами по ходу игры.

## Как играть

- Собирай **солнце** (падает с неба и производится подсолнухами).
- Тапни **пакетик с семенами** сверху, затем клетку газона — растение посажено.
- На последней волне появится **Королева Уток** (полоса её HP — внизу экрана):
  она сносит растения одним ударом и **ломает газонокосилки**. Снежный горох её
  не замедляет — понадобится серьёзная огневая мощь.
- Газонокосилка — последний рубеж в каждой полосе; сработала — сгорела.

| Растение    | Цена | Что делает                                           |
|-------------|-----:|------------------------------------------------------|
| Подсолнух   |   50 | Производит солнце                                    |
| Горохострел |  100 | Стреляет горошинами по своей полосе                  |
| Орех        |   50 | Дешёвая стена с большим запасом HP                   |
| Снежный горох | 175 | Горошины замедляют гусей (королеву — нет)            |
| Вишнёвая бомба | 150 | Фитиль, затем взрыв 3×3                              |
| Картофельная мина | 25 | Взводится и взрывается на гуся, который наступил |

Гуси: обычный, с конусом (больше HP), с ведром (ещё больше HP).

## Структура

```
src/game.h, src/game.c          — вся игра (логика + софтверный рендер, кириллица)
src/android_main.c              — Android-слой: native_app_glue + EGL/GLES2
tools/host_test.c               — десктоп-проверка (рендерит BMP-скриншоты)
tools/sim_test.c                — автосимуляция (стабильность/баланс)
AndroidManifest.xml             — app.pvg3, NativeActivity, Android 10+
LICENSE                         — MIT
.github/workflows/Build.yml     — сборка arm64+arm32 в один APK
```

## Сборка (Android APK)

Воркфлоу собирает **обе** ARM-архитектуры из одних исходников и пакует их в
**один** APK: `arm64-v8a` (64-бит) и `armeabi-v7a` (32-бит), min API 29
(Android 10+), target API 34. На выходе — артефакт `PvG3-Android-arm64-arm32`.

## Проверка локально (без устройства)

```sh
gcc -O2 -Wall -Isrc src/game.c tools/host_test.c -o host_test -lm
./host_test   # пишет shots/menu.bmp и shots/play.bmp
```
