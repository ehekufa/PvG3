# PvG3 — Растения против гусей

Игра для Android (C, NativeActivity + GLES2) с **авторскими рисунками из этого
репозитория**. Никакие дополнительные растения, гуси-противники или персонажи
не дорисовываются за игрока: в игре участвуют только герои и предметы,
для которых присланы PNG. Солнце, горошины и элементы интерфейса — простые
игровые эффекты, а не отдельные персонажи.

## Сюжет и уровни

В меню нажми **«ИГРАТЬ»**. В кат-сцене Хлебушек плачет, Дима в маске подходит
к нему и говорит: «Не плачь, мы нового сделаем». Кирилл спрашивает:
«Может, кто-то помогать мне будет?» Кат-сцена идёт автоматически; её можно
пролистать касаниями или пропустить.

После неё начинаются **уровни 1–10**. В обычных волнах наступают только
нарисованные автором **утки-зомби** (их количество и прочность растут);
выдуманных врагов с конусом или ведром нет. После каждой победы нажми
«ДАЛЬШЕ». В конце десятого уровня после волны уток приходит Королева в
нарисованном большом роботе. Робот медленный, топчет растения сразу в трёх
рядах, ломает газонокосилки и не замедляется снежным горохом. За его
здоровьем следи по полоске внизу. Если проиграешь, можно повторить текущий
уровень.

## Управление

Выбери пакетик с семенами сверху, затем свободную клетку газона. Доступны
только три растения с рисунками автора:

| Растение | Цена | Действие |
|---|---:|---|
| Горохострел | 100 | Стреляет по уткам в своём ряду |
| Орех | 50 | Прочная стена |
| Снежный горох | 175 | Стреляет и замедляет уток (не робота) |

Тапай на падающее **солнце**, чтобы получать очки для посадки: подсолнуха на
панели больше нет, поэтому солнце регулярно падает с неба. Газонокосилка —
одноразовая защита каждого ряда; на робота она не действует. Кнопка **МЕНЮ**
возвращает на начальный экран и начинает новую игру с первого уровня.

## Сборка и проверка

`tools/pack_sprites.py` превращает оригинальные PNG в переносимый RLE-заголовок
`src/sprites_data.h` без сторонних библиотек. Оба файла есть в репозитории:
обычная сборка APK не требует ручной генерации. Если поменяешь PNG, обнови
заголовок командой `python3 tools/pack_sprites.py`.

GitHub Actions собирает один APK для `arm64-v8a` и `armeabi-v7a`, Android 10+
(API 29). Результат — артефакт `PvG3-Android-arm64-arm32` из workflow
**Build PvG3 (Android APK, arm64 + arm32)**.

Локально без Android можно создать скриншоты `shots/*.bmp` и проверить
проход через все десять уровней:

```sh
gcc -std=c11 -O2 -Wall -Wextra -Isrc src/game.c tools/host_test.c -o host_test -lm
./host_test

gcc -std=c11 -O2 -Wall -Wextra -DGAME_TEST -Isrc src/game.c tools/sim_test.c -o sim_test -lm
./sim_test
```
